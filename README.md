# Face Detection using OpenCV

## Overview
This project implements real-time face detection using OpenCV and computer vision techniques.

The application captures webcam input and detects faces in real time.
---

## Features
* Real-time webcam detection
* Face localization
* Live video feed
* Image capture functionality
* Computer vision implementation
---

## Technologies Used
* Python
* OpenCV
* NumPy
---

## Workflow
1. Capture webcam feed
2. Convert frames to grayscale
3. Detect faces
4. Draw bounding boxes
5. Display results
---

## Installation
Install requirements:
pip install opencv-python numpy

Run:
python face_detection.py
---
## Controls

Press:
Q → Quit application
C → Capture image
